How to compare builds

A quick walkthrough of the Build A / Build B comparison workflow.

  1. Fill out Build A — Character, Wheel of Destiny, Weapon & Proficiency, perks, rotation and targets.
  2. Switch to Build B and either start from scratch, or click Import Build A to copy Build A over so you can tweak just a few things.
  3. Open the Results tab — both builds calculate automatically, and stay in sync whenever you come back after making a change.
  4. Every card shows a percentage badge comparing it to the other build: green means that build is stronger on that metric, red means it's weaker.
  5. Use Copy build link in the header to share the full A/B comparison with someone else — opening the link restores both builds.
  6. The Reset button only clears whichever build tab (A or B) you're currently viewing.
